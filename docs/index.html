snapgene_edit 纯 Python

读取、编辑和写入 SnapGene .dna 文件的纯 Python 库，无需 SnapGene 软件。

零外部依赖 — 仅使用 Python 标准库（struct、xml.etree.ElementTree 等），安装即用。

功能一览

  • 📂 读取 SnapGene .dna 二进制文件 → SnapGeneFile 对象
  • ✏️ 编辑序列（替换、插入、删除区域），特征坐标自动调整
  • 🏷️ 管理特征（添加、删除、重命名、修改坐标）
  • 🧬 批量编辑 sgRNA 特征：替换序列 + 重命名，支持 A/B/C/G 四种荧光变体
  • 💾 保持原始块顺序写入，最大兼容 SnapGene

安装

# 直接从 GitHub 安装（推荐）
pip install git+https://github.com/li1311139481/snapgene_edit.git

# 或先 clone 后以可编辑模式安装（修改源码即时生效）
git clone https://github.com/li1311139481/snapgene_edit.git
pip install -e snapgene_edit

SnapGeneEditor — 核心编辑器

最常用的入口类。支持打开现有 .dna 文件或从零创建。

class SnapGeneEditor

构造

# 从已有文件加载
editor = SnapGeneEditor("plasmid.dna")

# 从 SnapGeneFile 对象
editor = SnapGeneEditor(data=snapgene_file)

# 从零创建
editor = SnapGeneEditor()

属性

属性类型说明
namestr质粒/序列名称（可读写）
sequencestrDNA 序列（只读）
lengthint序列长度 (bp)
featuresList[Feature]特征列表
is_circularbool是否环状（可读写）

序列编辑方法

  • replace_region(start, end, new_seq)
    替换指定区域（特征自动调整）
  • insert(position, new_seq)
    在指定位置插入序列
  • delete_region(start, end)
    删除指定区域
  • replace_sequence(old_seq, new_seq, *, all=True)
    按序列内容替换（全部或首次）
  • set_sequence(seq)
    替换整个序列（清空所有特征）

特征编辑方法

  • add_feature(name, start, end, *, feature_type, strand, color)
    添加新特征
  • remove_feature(name)
    移除指定特征
  • rename_feature(old_name, new_name)
    重命名特征
  • update_feature_coords(name, start, end)
    手动更新特征坐标
  • find_feature(name) → Feature | None
    按名称查找特征
  • list_features() → List[dict]
    所有特征的摘要字典列表
  • replace_in_feature(feature_name, new_seq) → bool
    替换指定特征区域内的序列
  • insert_in_feature(feature_name, new_seq, *, at)
    在特征区域内插入序列

保存 / 重载

  • save(path)
    保存到指定路径
  • save_overwrite()
    覆盖保存到原文件
  • reload()
    重新加载（丢弃未保存修改）

特征坐标自动调整

replace_region、insert、delete_region 方法在修改序列的同时会自动调整所有特征的坐标。

调整规则
特征位置处理方式
完全在编辑区域之前start / end 不变
完全在编辑区域之后start 和 end 同时加上长度增量 len(new_seq) - old_len
完全在编辑区域之内序列完全改变，特征删除
部分重叠重叠部分删除；非重叠部分保留原名
示例

将位置 10-30（20bp）替换为 4bp 序列：

# 编辑前: [sgRNA:10-30] [GeneA:25-40] [GeneB:50-80]
# 替换后: [sgRNA:10-14] [GeneA:14-24] [GeneB:34-64]

editor.replace_region(10, 30, "AAAA")

GeneA[25-40] 部分重叠，右半 [30-40) 存活 → 平移至 [14-24)
GeneB[50-80] 完全在编辑区域后 → 平移 -16 → [34-64)

批量 sgRNA 编辑

专为 sgRNA 克隆设计的纯配置驱动接口。根据荧光标识自动选择模板文件，无需手动传 src_file。

核心流程：读取模板 → 找到名为 sgRNA 的特征 → 替换序列 → 重命名 → 保存 → 输出引物。

function batch_from_lists_simple(save_names, new_names, new_seqs, fluor_list, output_dir, fluor_files)

这是项目中唯一公开的批量接口，所有其他批量函数均已合并至此。

参数

参数类型说明
save_namesList[str]输出文件名（不含路径和 .dna 后缀）
new_namesList[str]新的 sgRNA 特征名称
new_seqsList[str]新序列；写 "FLUOR" 自动使用对应荧光的原始 sgRNA 序列
fluor_listList[str]荧光标识（A / B / C / G），与 new_seqs 一一对应
output_dirstr输出目录（默认为当前目录）
fluor_filesDict[str, str]自定义荧光→模板路径映射（默认使用 config.py 中的配置）

返回值

返回一个字符串，包含处理日志和引物序列（正向 + 反向互补），可直接粘贴到 primer list。同时 print() 输出到控制台。

from snapgene_edit import batch_from_lists_simple

result = batch_from_lists_simple(
    save_names=["ZFP001", "ZFP002", "ZFP003"],
    new_names=["sgKlf2-1", "sgKlf2-2", "sgKlf2-3"],
    new_seqs=["FLUOR", "FLUOR", "AAAAAAAAAAAAAAAAAAAA"],
    fluor_list=["A", "B", "A"],
    output_dir=r"D:\plasmid\temp",
)
print(result)

配置 — config.py

荧光模板文件的路径映射。修改此文件即可更新模板路径，无需修改代码。

# snapgene_edit/config.py
FLUORESCENT_FILES = {
    "A": "D:/plasmid/LMA模板.dna",
    "B": "D:/plasmid/LMB模板.dna",
    "C": "D:/plasmid/LMC模板.dna",
    "G": "D:/plasmid/LMG模板.dna",
}
要求：每个模板 .dna 文件中必须包含一个名为 sgRNA 的特征。batch_from_lists_simple 会读取该特征的序列作为模板。
提示：若不想修改 config.py，也可通过 fluor_files 参数传入自定义路径映射。

完整使用示例

from snapgene_edit import SnapGeneEditor

editor = SnapGeneEditor(r"D:\plasmid\my_plasmid.dna")

print(f"名称: {editor.name}")
print(f"长度: {editor.length} bp")
print(f"环状: {editor.is_circular}")
print(f"特征数: {len(editor.features)}")

for f in editor.list_features():
    print(f"  - {f['name']} ({f['type']}) [{f['start']}:{f['end']}]")
from snapgene_edit import SnapGeneEditor

editor = SnapGeneEditor()
editor.name = "my_plasmid"
editor.set_sequence("ATGCGATCGTAGCTAGCTAGCTAGCGCGATCGATCGTACGTAGC")
editor.is_circular = True

# 添加特征
editor.add_feature("GFP", 0, 15, feature_type="CDS", strand=1, color="#00FF00")
editor.add_feature("Promoter", 20, 35, feature_type="promoter", color="#FF0000")

# 编辑序列（特征坐标自动调整）
editor.insert(15, "AAAA")
editor.replace_region(10, 14, "GGGG")

# 保存
editor.save(r"D:\plasmid\output.dna")
from snapgene_edit import batch_from_lists_simple

result = batch_from_lists_simple(
    save_names=["ZFP001", "ZFP002", "ZFP003", "ZFP004"],
    new_names=["sgKlf2-1", "sgKlf2-2", "sgKlf2-3", "sgKlf2-4"],
    new_seqs=["FLUOR", "FLUOR", "AAAAAAAAAAAAAAAAAAAA", "TTTTTTTTTTTTTTTTTTTT"],
    fluor_list=["A", "B", "A", "A"],
    output_dir=r"D:\plasmid\temp",
)
print(result)
